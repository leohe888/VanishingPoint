## 实施约定

- 每阶段日志记录：具体修改、验证命令/结果、失败与修正、提交标识。阶段提交本身包含该阶段日志，后续日志记录其 SHA。
- 烘焙选中图像及其下方图像，保留上方图像，保持显示层序；可整体撤销。
- 选区超过 8192 任一边或 64 MiB 输出预算时拒绝并提示，避免静默裁剪；不新增图层框架。
- 保持现有最小实际面积 50，明确命名并统一挤出判断，避免无依据改变已有用户操作阈值。
- 安全透视映射拒绝非有限值与齐次极点；允许合法外推；笔触不得跨极点。
- 性能候选逐项评估：实施有明确收益的小改动；未经测量的修订号缓存、复杂缓冲/插件框架不引入，日志必须记录理由，不能遗漏。
- 保留 bitmapClip、撤销快照与曲面快照，以及解析几何与跨面片测试。
- 回退使用对应阶段的 git revert；基线仅供定位，不执行会丢失后续工作的 reset。
